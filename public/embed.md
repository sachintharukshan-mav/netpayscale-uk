## 2. Supported Parameters

Customize the embed widget URL with query parameters:
- **band**: Set default pay band (e.g. `?band=band-5`, `?band=band-6`, `?band=band-2`). Defaults to Band 5.
- **theme**: Set visual theme (`?theme=light` or `?theme=dark`).
- **region**: Set default London weighting (`?region=inner`, `?region=outer`, `?region=fringe`, `?region=standard`).
